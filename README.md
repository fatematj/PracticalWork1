# Практическая работа № 1

В рамках практической работы реализованы рекурсивные задачи на Java.

## Структура проекта

Основные классы:

- `Factorial` — рекурсивный расчет факториала в двух вариантах:
  - с результатом типа `long`
  - с результатом типа `BigInteger`

- `FirstTask` — Задача 6: «Количество цифр в строке».

- `SecondTask` — Задача 7: «Числа Фибоначчи».

Для каждой задачи созданы JUnit-тесты, проверяющие базовые и рекурсивные случаи.
